## Mise en ligne
1. Mets ces trois fichiers sur un hébergeur statique (GitHub Pages, Netlify, Vercel, etc.).
2. Récupère l'URL HTTPS publique.
3. Programme une carte NFC NTAG213/215/216 avec cette URL.
4. Le client approche son téléphone : la page s'ouvre.
